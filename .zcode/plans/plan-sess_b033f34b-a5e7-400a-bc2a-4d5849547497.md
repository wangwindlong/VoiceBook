# Calibre-Web 跨平台阅读功能实现方案

在 shared/commonMain 新增 `us.wangxy.voicebook.reader` 包，全平台（Android/iOS/桌面/Web）共用一套 UI 与逻辑，遵循现有模式：navigation-compose 类型安全路由 + Koin + ViewModel/StateFlow + coil3 图片。代码风格遵循仓库先例（手写 common Kotlin 解压器如 BZip2Source/TarExtractor）。

## 一、数据层

**1. `reader/xml/XmlReader.kt`** — 手写最小 XML pull 解析器（事件流：StartTag(name, attrs)/Text/EndTag），处理声明/注释/CDATA/实体，按 localName 匹配忽略命名空间前缀。OPDS(Atom) 与 EPUB 的 container.xml/OPF 都靠它。

**2. `reader/opds/OpdsParser.kt` + `reader/api/CalibreWebApi.kt`** — 对接 calibre-web OPDS 1.2：
- 书架：`GET {url}/opds/new?offset=N`（offset 分页，下拉加载更多）
- 搜索：`GET {url}/opds/search/{query}`
- 封面：`{url}/opds/cover/{bookId}`；下载：条目里的 acquisition 链接（`/opds/download/{id}/EPUB/`）
- 认证：HTTP Basic（复用现有 Koin 的 HttpClient，请求级 `basicAuth()`），服务器地址/账号存设置

**3. `reader/epub/`** — EPUB 解析（EPUB=ZIP，整本书以 ByteArray 读入内存，通常 0.5~5MB，四端统一、Web 也可用）：
- `Inflate.kt`：RFC1951 解压（stored/固定/动态 Huffman），仿 BZip2Source 风格的 common Kotlin 实现
- `ZipReader.kt`：读 End-of-Central-Directory + 中央目录，`entryNames()` / `read(name): ByteArray`
- `EpubBook.kt`：container.xml → content.opf → manifest/spine → 章节列表（书名/作者/封面/各章 xhtml 懒解析），`imageBytes(href)` 供插图
- `HtmlParser.kt`：XHTML 子集 → `List<Block>`（标题 h1-h6 / 段落（粗斜体 span、段首缩进）/ 引用 / 列表 / `<img>` → Image 块）
- `ImageSize.kt`：PNG/JPEG/GIF 头部宽高探测（分页需要先知道图片占多高，无需解码全图）；SVG 显示占位

**4. `reader/paginate/Paginator.kt`** — TextMeasurer 按视口宽高把 Block 切成页（段落按行高切片、整段不可拆的标题独占、图片按宽高比缩放整块放页）；每页暴露起始 charOffset 用于存/恢复位置；字号变化时以当前 charOffset 为锚重排。

**5. `reader/store/`** — 服务器配置 + 阅读历史持久化：
- `ReaderStateStore.kt`：`{server, history[]}` JSON；Flow 驱动，变更即存
- expect/actual 存储：Android `filesDir/reader/state.json`（Context 已在 Koin）；JVM `~/.voicebook/reader/`；iOS Documents 目录；Web localStorage
- `HistoryEntry(bookId, title, author, coverUrl, spineIndex, charOffset, updatedAt, 进度%)`

## 二、UI 层

**6. `screens/library/`** — 书城首页（选定布局：继续阅读横条 + 书架）：
- 顶栏：标题 + 搜索入口 + 服务器设置（对话框：地址/用户名/密码/测试连接）
- 「继续阅读」横向卡片行：历史记录倒序，封面+书名+进度%+▶继续
- 书架：3 列封面网格（coil AsyncImage，封面请求带 Basic auth header），滚动到底自动加载下一页（offset）
- 未配置服务器 → 引导卡片；搜索页：输入 → 结果网格

**7. `screens/reader/`** — 阅读器：
- 打开流程：下载 EPUB（进度条）→ 解析 → 从历史恢复位置 → 分页 → 定位到对应页
- HorizontalPager 左右翻页；点按左/右 1/3 翻页、中间切换工具栏
- 工具栏：书名/章节、返回、进度%、字号 A-/A+（重排并锚定当前位置）、目录按钮（spine 章节列表弹层跳转）
- 插图：Image 块经 coil 自定义 Fetcher 从内存中的 EpubBook 取字节解码（后备 `decodeToImageBitmap`）
- **续读**：翻页落定/退出时保存 (spineIndex, charOffset)；重进自动定位

**8. 接入** — `App.kt` 加 `LibraryDestination`、`ReaderDestination(bookId, title, author, coverUrl)` 路由；ListScreen 加"书城"入口；`Koin.kt` 注册 `readerModule`。

## 三、测试与验证

- commonTest：XmlReader / OpdsParser（内嵌真实 calibre-web feed 样例）/ HtmlParser / ImageSize
- jvmTest：用 `java.util.zip` 生成压缩数据反向验证手写 Inflate+ZipReader；测试内组装最小 EPUB 走通 EpubBook；历史存取 roundtrip；分页切片数学（假测量器）
- 端到端自测：本地起一个 mock OPDS 服务（python 单文件 + 真实 EPUB）跑 desktopApp 验证书架加载→下载→阅读→退出→重进恢复位置。你拿到后在自己服务器设置里填地址即可联调

## 四、v1 边界（不做）

CSS 高级排版（字体/颜色/浮动）、SVG 插图、字体切换、TTS 朗读、PDF/其他格式（仅 EPUB）。

## 风险点

- calibre-web 各版本 OPDS 略有差异 → 解析按 OPDS 1.2 规范宽松处理 + 真实样例单测
- 手写 inflate 有正确性风险 → 用 JVM java.util.zip 生成大量随机 fixture 压力测试
- wasm/js 端 coil 网络加载需手动配 ImageLoader（必要时 Web 端封面先降级为占位色块，桌面/Android/iOS 全功能）
